## 第一阶段：环境自检与首次使用

### 获取匹配设备的官方包

从固定版本发行页选择 Windows x86_64/arm64、macOS（darwin）x86_64/arm64 或适合 Linux 的附件。页面还提供 checksums 文件，可用于核对下载文件；本收藏未下载或验证这些发行二进制。

解压到单独目录，先阅读[官方开始使用说明](source/docs/guide/start.md)。macOS 另见[官方 macOS 指南](source/docs/guide/macos.md)。普通运行不需要安装 Go；源码开发才需要开发环境。

### 理解证书与代理变化

上游 README 要求管理员身份运行；首次启动会安装根证书并启动代理。根证书与系统代理会影响本机的信任和网络流量处理，运行前应确认来源及影响范围。收藏操作不等于同意安装证书或改变代理，本次未执行这些动作。

按上游流程完成启动后，看到“代理服务启动成功”再打开微信 PC 端。本工具的自检以服务日志和页面按钮为主，不需要套用通用 doctor 初始化命令。

## 第二阶段：核心工作流

1. 打开微信 PC 端，进入需要保存的视频号视频。
2. 等待视频开始播放，再暂停。
3. 点击视频下方新增的下载按钮；也可能通过侧边或底部的悬浮按钮进入。
4. 默认按钮下载当前播放质量；需要其他质量时查看下拉菜单。
5. 在下载记录及保存目录中核对文件、清晰度和播放结果。

![上游下载按钮示例](source/docs/assets/screenshot1.png)

后台下载目录按[下载配置](source/docs/config/download.md)设置；前端与后台下载行为不同，不应假设所有模式都使用同一目录。

该正式版发行说明还列出原始视频下载优化，以及 Bilibili、YouTube、快手支持。这些是上游发布声明，本收藏未逐平台验证；本指南以视频号基本流程为主。

### 常见问题

| 现象 | 核对方式 |
| :--- | :--- |
| 看不到下载按钮 | 确认下载器已启动、代理符合上游说明，再刷新页面或重新进入详情；参见[按钮缺失排查](source/docs/faq/button_inject_failed.md) |
| 不知道文件保存位置 | 核对前端/后台下载模式和配置，参见[下载设置](source/docs/config/download.md) |
| 证书或代理异常 | 先停止服务，再按上游说明核对本工具配置；不要盲目更改其他软件的代理或证书 |
| 新版微信不兼容 | 查看上游 Issues 与后续发行说明；固定快照不保证适配微信未来更新 |

### 停止、更新与卸载

- 停止运行：按[服务命令说明](source/docs/cli/server.md)操作，前台终端可使用 Ctrl+C。随后核对系统代理状态。
- 更新：退出旧程序，从官方发行页下载匹配平台的新包；先保存自己的配置和已下载文件。
- 卸载根证书：上游提供 `wx_video_download uninstall`，实际可执行文件名依下载包而异，详见[卸载说明](source/docs/cli/uninstall.md)。再次运行可能重新安装证书；操作前核对目标证书与权限。
- 完整移除：停止服务、处理本工具的代理与证书后，再移除程序目录；保留需要的下载文件和配置。只删除可执行文件不代表证书已卸载。
