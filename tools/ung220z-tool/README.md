# ung220z-tool · 中国移动光猫凭据提取工具

> 🔗 **原项目 GitHub 地址**：[Hut-hzf/ung220z-tool](https://github.com/Hut-hzf/ung220z-tool)

针对 **UNG220Z（九联 / Unionman 中国移动光猫）** 的自动化凭据提取工具。针对此类光猫 Web 超级密码被 TR-069 平台定期下发轮换导致普通管理失效的问题，工具通过调用光猫 Web 接口尝试开启 Telnet 服务，建立 Telnet 终端执行配置库解密命令（`sidbg 1 DB decry`），一键导出当下有效的 Web 超级管理员账号、Telnet 口令、PPPoE 拨号账号与密码、Wi-Fi 密钥及 root 口令。

> ⚠️ **合规提示**：本工具仅限个人在自有光猫设备上用于找回遗忘的管理密码、宽带改桥接/换路由配置迁移或安全自查；严禁对非授权网络设备使用。

## 第一阶段：环境自检与首次使用

### 1. 运行环境与网络自检

1. **Python 环境自检**：
   在终端确认 Python 版本不低于 3.8：
   ```bash
   python3 --version
   ```
2. **物理与局域网连通**：
   - 电脑网线插入光猫的千兆 LAN 口（或连接光猫自带 Wi-Fi）。
   - 确认本机获取到光猫分配的内网 IP（通常在 `192.168.1.0/24` 网段）。
   - 终端测试连通性：
     ```bash
     ping 192.168.1.1
     ```

### 2. 准备基础凭据

翻看光猫**背面铭牌贴纸**，记录出厂默认配置信息：
- 默认终端配置地址（通常为 `192.168.1.1`）
- 普通用户账号（通常为 `user`）
- 默认用户密码（贴纸上的随机字符）

### 3. 获取与启动脚本

进入快照目录或提取 `source/ung220z.py` 到本地工作目录：

```bash
cd tools/ung220z-tool/source
python3 ung220z.py
```

终端将提供交互式提示，依次输入光猫 IP、用户名和密码即可开始自动化流程。

## 第二阶段：核心工作流

### 1. 命令行参数化调用

除交互模式外，支持直接传入参数执行非交互提取：

```bash
# 自动通过浏览器与 HTTP 兜底开 Telnet 并提取凭据
python3 ung220z.py -i 192.168.1.1 -u user -p '你的普通密码'

# 纯命令行模式（无 GUI 桌面环境或远程服务器操作时使用，不唤起系统浏览器）
python3 ung220z.py -i 192.168.1.1 -u user -p '你的普通密码' --no-browser
```

### 2. 常用参数一览

| 参数 | 默认值 | 作用说明 |
| :--- | :--- | :--- |
| `-i, --ip` | `192.168.1.1` | 光猫管理页面 IP 地址 |
| `-u, --user` | `user` | 光猫普通用户登录账号 |
| `-p, --password` | *(交互输入)* | 光猫普通用户登录密码 |
| `--telnet-user` | `CMCCAdmin` | Telnet 登录账号 |
| `--telnet-password` | *(空)* | Telnet 专用口令（部分固件版本与 Web 口令不同时指定） |
| `--no-browser` | 关闭 | 禁用调用系统默认浏览器打开 `telnet.gch`，仅由脚本发送 HTTP 请求 |
| `--unlock` | 关闭 | 若 Web 端被残留会话锁占用，尝试通过重启 httpd 解锁 |
| `--no-release` | 关闭 | 退出时不主动发送请求释放 Web 登录会话 |

### 3. 结果查看与输出说明

脚本执行时将实时在控制台打印各阶段状态，并在执行完毕后：
1. 在控制台格式化输出凭据汇总表（含超级管理员账号 `CMCCAdmin`、密码、PPPoE 宽带账号密码、Wi-Fi SSID 与密码等）。
2. 在当前目录下自动生成带时间戳的审计日志文件 `ung220z_<时间戳>.log` 供查阅。

### 4. 常见故障排查

| 故障现象 | 排查与解决办法 |
| :--- | :--- |
| `telnet.gch` 返回 404 或未开启成功 | 固件已被运营商新版补丁封堵该隐藏接口；检查光猫 IP 是否输入正确，或尝试通过浏览器手动访问对应 URL 测试 |
| Telnet 端口 23 连接超时 | 确认本机防火墙未阻断出站连接；确认电脑与光猫 LAN 口处于同一二层网络，未经过多层路由隔离 |
| 提示 Web 会话被占用锁定 | 增加 `--unlock` 参数运行，或拔插光猫电源重启后再试 |
| 无法解密配置文件 | 检查光猫型号是否为 UNG220Z，其他型号厂商使用的内部解密工具命令（非 `sidbg`）可能不同 |
