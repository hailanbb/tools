# Piko · 高性能多平台 PikPak 客户端

> 🔗 **原项目 GitHub 地址**：[NihilDigit/piko](https://github.com/NihilDigit/piko)

**Piko** 是基于 Kotlin 与 Compose Multiplatform 深度打磨的高性能、多平台第三方 PikPak 网盘客户端，原生适配 Android、Windows、macOS 与 Linux。软件专为网盘重度用户与影音收藏爱好者设计，在支持多连接并发极速下载、多节点智能测速与弱网优化的同时，提供了自适应海报墙、信息流短视频切片滑动预览、磁力与种子智能解析、压缩包免解压在线浏览、重复文件排重及多账号加密保存等高级生产力特性。

## 第一阶段：环境自检与首次使用

### 1. 跨平台版本获取

前往 [Piko 官方 Releases 页面](https://github.com/NihilDigit/piko/releases/tag/v1.2.0) 根据设备类型下载对应构建包：

| 设备类型 | 推荐下载文件 | 说明 |
| :--- | :--- | :--- |
| **Android 手机 / 平板** | `piko-1.2.0-arm64-v8a.apk` | 绝大多数主流 Android 设备适用；不确定架构选 `universal.apk` |
| **Windows 电脑 (x64)** | `piko-windows-x64-1.2.0.msi` 或 `.7z` | `.msi` 为用户级免管理员安装版；`.7z` 为绿色便携版 |
| **Windows on ARM** | `piko-windows-arm64-1.2.0.msi` 或 `.7z` | 针对骁龙等 ARM64 Windows 11 设备原生编译 |
| **macOS (Apple Silicon)** | `piko-macos-arm64-1.2.0.dmg` | 适用于 M 系列芯片，挂载拖入 Applications 即可 |
| **Linux (x64)** | `piko-linux-x64-1.2.0.AppImage` | 需 glibc 2.38+，赋予执行权限后直接启动 |

### 2. 便携版与数据隔离特性

* **完全便携化**：Windows 便携版的所有登录数据与应用缓存均保存在程序根目录的 `data/` 文件夹中，不写入系统用户目录。直接拷贝文件夹即可在任意电脑即插即用，删除文件夹即彻底移除所有数据。
* **首次登录与多账号管理**：支持多账号安全切换，凭据由操作系统底层密钥库加密保存。

## 第二阶段：核心工作流

### 1. 链接解析与极速传输

* **智能链接解析**：输入磁力链接、种子文件或网盘分享链接，保存前支持展开文件树完整预览，自动按作品与集数归类收拢，智能隐藏非正片样本与花絮。
* **多连接并发下载**：下载引擎采用动态多连接并发，自动绕开响应缓慢的节点，在弱网环境下保持高吞吐；支持一键整文件夹下载与可选画质转码导出。
* **蜗牛限速模式**：在后台大文件传输时开启蜗牛限速，确保不影响前台在线高清观影。

### 2. 网盘文件浏览与智能整理

* **压缩包在线直接打开**：ZIP、RAR、7z 等常见格式压缩包无需下载解压，可直接像常规文件夹一样逐层点开浏览，压缩包密码按账号加密同步。
* **智能整理与批量改名**：重构的批量重命名面板支持正则表达式、序列递增与前后缀预览；支持按番号规范命名并自动获取标准片名。
* **无损归档机制**：支持将文件或文件夹转为不占网盘配额的归档记录，记录永久保存来源磁力链接，支持随时按需一键取回。
* **重复文件排查**：内置智能查重工具，按分组对比展示相似度与文件大小，辅助批量清理冗余。

### 3. 信息流体验与高清播放

* **片段信息流**：网盘右侧内置信息流面板，上下滑动即可快速连贯预览当前目录中各个影片的精彩片段。
* **专业级播放控制**：内置播放器支持硬件解码开关、跨集保留画质与倍速、字幕模糊匹配与外部播放器调用。

## 排障与日常维护

* **安装拦截放行**：
  - Windows：若出现 SmartScreen 拦截提示，点击「更多信息」→「仍要运行」。
  - macOS：安装包未经公证，首次启动被拦截时，在「系统设置」→「隐私与安全性」中点击「仍要打开」。
* **网络播放慢或中断**：建议在设置中开启多连接并发或调整缓冲大小；若网络运营商对默认节点有限制，客户端会自动尝试降级节点。
* **卸载与清理**：
  - 便携版：直接删除 Piko 程序目录即可彻底删除所有数据。
  - 安装版：在系统设置“已安装的应用”中正常卸载。
