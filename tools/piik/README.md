## 第一阶段：环境自检与首次使用

### 1. 三种使用形态

* **在线版（免安装）**：直接在桌面浏览器访问 [demo.piik.tv](https://demo.piik.tv)，即开即用（受限于公共网络环境，适合快速临时开播）。
* **Piik App 客户端（推荐房主使用）**：提供低延迟原生屏幕采集、游戏声音内录与麦克风解说，支持 Windows、macOS 及 Linux。
* **自建 Piik Server 站点（推荐进阶用户）**：单个 Go 静态二进制文件，打包内置完整 Web 前端与 SFU 媒体分发服务，支持绑定专属域名与私有化房间。

### 2. 客户端（Piik App）快速上手

1. 前往 [Piik Releases 页面](https://github.com/TNTcraftHIM/Piik/releases/tag/v1.9.2) 下载对应系统的客户端压缩包：
   - **Windows**：`piik-app-windows-amd64.zip`
   - **macOS (Apple Silicon)**：`piik-app-darwin-arm64.zip`
   - **macOS (Intel)**：`piik-app-darwin-amd64.zip`
   - **Linux**：`piik-app-linux-amd64.zip` / `arm64.zip`
2. 解压并打开 Piik App：
   - 方式一：选择**公网邀请**，点击**进入 Piik**，系统将自动分配临时房间。
   - 方式二：填入自建 Piik Server 的域名（如 `https://live.example.com`）连接私有站点。
3. 点击**开始分享**，选择要共享的完整屏幕、特定应用窗口或浏览器标签页，勾选同时分享系统音频。
4. 复制生成的房间邀请链接发给朋友，分享期间保持 App 正常运行。

### 3. 服务端独立自部署（Piik Server）

Piik Server 为纯静态单二进制程序，房间元数据保存在嵌入式 SQLite 中：

```bash
# 1. 下载并解压服务端运行时（以 Linux x64 为例）
tar -zxvf piik-390e637-runtime.tar.gz

# 2. 启动服务（默认监听 8787 端口）
./piik-server
```

启动后在本机访问 `http://localhost:8787` 即可体验。生产环境建议通过 Nginx / Caddy 配置域名并启用 HTTPS 反向代理。

## 第二阶段：核心工作流

### 1. 灵活的屏幕采集与声音管理

* **多源画面选择**：自由切换全屏幕捕获、独立游戏窗口、单独浏览器页面或物理摄像头。
* **混音与解说**：在分享系统音频的同时可独立开启麦克风语音，内置人声音量增益调节与回声抑制。

### 2. 零门槛协同观影与互动体验

* **浏览器免安装即看**：朋友收到链接后点击即可直接在移动端或电脑浏览器内观看，支持清晰度自适应与全屏/画中画播放。
* **客厅互动模式**：支持实时房间文字聊天、表情符号互动，并支持将聊天内容直接渲染为画面悬浮弹幕。
* **房间管理与私密保护**：支持自定义房间号、临时邀请码以及独立房间密码，单房间支持房主与最多 20 位朋友同屏观看。

### 3. 传输机制与网络拓扑

* **P2P 直连优先**：画面与音频流优先在房主与观众设备间建立点对点加密传输，不消耗服务器中转带宽。
* **SFU 媒体转发自动降级**：自建站点可启用内置 SFU 服务，在复杂网络（如对称型 NAT、移动热点）导致 P2P 穿透失败时自动无缝切换为服务器转发。

## 排障与日常维护

* **浏览器画面无法分享**：Web 端屏幕采集受 WebRTC 规范限制，必须在 `https://` 域名下或 `http://localhost` 本地环回地址中运行。
* **朋友打不开或连接失败**：纯 P2P 临时公网邀请模式在严苛的企业内网或多层 NAT 下可能无法连通，建议部署私有 Piik Server 并配置有效的 STUN/TURN 服务器。
* **客户端卸载**：Piik App 为免安装绿色软件，直接删除解压目录及配置文件即可干净卸载。
