# LinkSwift · 网盘文件直链下载助手

> 🔗 **原项目 GitHub 地址**：[hmjz100/LinkSwift](https://github.com/hmjz100/LinkSwift)

基于 JavaScript 开发的浏览器用户脚本（Userscript），用于在网页端解析并获取常见网盘的文件高速下载直链。基于“网盘直链下载助手”修改重构，支持百度网盘、阿里云盘、中国移动云盘、天翼云盘、迅雷云盘、夸克网盘、UC网盘、123云盘等八大网盘，可配合 IDM、Aria2、Motrix、curl 等多线程下载工具使用。

## 第一阶段：环境自检与首次使用

### 1. 浏览器与脚本管理器自检

LinkSwift 为前端 UserScript，依赖现代浏览器及油猴脚本管理器：

1. **浏览器环境**：建议使用基于 Chromium 内核的最新浏览器（如 Google Chrome ≥ 76、Microsoft Edge）或 Mozilla Firefox。
2. **脚本扩展**：确认浏览器已安装以下脚本管理器之一：
   - [Tampermonkey（篡改猴）](https://www.tampermonkey.net/)
   - [ScriptCat（脚本猫）](https://scriptcat.org/)
3. **扩展权限**：在 Chromium 核心浏览器中，进入扩展程序管理界面确认已为脚本管理器开启“开发者模式”及读取访问权限。

### 2. 安装与载入脚本

- **本地源码载入**：在脚本管理器的“实用工具”中选择从文件导入，选择本次快照中的 `source/（改）网盘直链下载助手.user.js`。
- **发布源安装**：亦可在脚本管理器中直接访问官方发布的 Releases 资产或官方 ScriptCat/GreasyFork 页面进行安装。
- **扩展配合**：针对百度网盘青春版等特殊页面，源码中配套提供了 `source/（改）百度网盘会员青春版.user.js` 可选安装。

### 3. 首次启用与界面自检

脚本属于前端注入式应用，不含命令行诊断命令：

1. 打开受支持的网盘 Web 端（如百度网盘网页版文件列表页面），确保已正常登录网盘账号。
2. 刷新页面，检查网页顶栏操作栏或文件多选菜单旁是否注入显示 **“下载助手”** 按钮。
3. 点击“下载助手”唤出功能菜单，检查“助手设置”、“更新日志”及各网盘的下载方式选项弹窗是否正常弹出。

## 第二阶段：核心工作流

### 1. 网盘直链提取流程

在网盘文件列表中勾选需下载的文件（单文件或批量文件）：

1. 点击顶栏出现的主题按钮 **“下载助手”**。
2. 在下拉菜单中选择所需的获取方式：
   - **API 直链下载**：直接调用网页接口换取包含鉴权凭据的文件直链。
   - **复制链接**：提取真实下载 URL，复制后粘贴至下载工具。
   - **cURL 命令**：生成带有 User-Agent 与 Cookie 头部的终端下载命令，便于服务器或无界面终端下载。
   - **RPC 下载**：通过 JSON-RPC 协议将下载任务一键推送到本地运行的下载器。

### 2. 配合多线程下载器（Aria2 / Motrix / IDM）

针对受限速或需要特定请求头的网盘链接：

- **RPC 联动配置**：
  在“下载助手”设置面板中，配置 RPC 参数：
  - 默认 RPC 地址：`http://localhost:6800/jsonrpc`
  - 授权密钥（Token）：填入本地 Aria2 / Motrix 配置的 RPC 密码
  - 路径与线程：设置默认保存目录与分块数（建议按网盘特性控制在 4~16 线程）。
- **IDM 配合**：
  在 IDM 的“选项” -> “下载” -> “手动添加下载任务的默认用户代理(UA)”中，需按脚本设置界面提示匹配相应的网盘客户端 UA，避免网盘服务端校验 User-Agent 阻断下载。

### 3. 常见问题、更新与卸载

| 现象 | 排查与解决方法 |
| :--- | :--- |
| 网盘页面未显示“下载助手”按钮 | 确认脚本管理器处于开启状态；检查网盘 URL 是否匹配 `@match` 规则；尝试强制刷新（Ctrl+F5） |
| 提示获取直链失败或返回 403/401 | 网盘反爬策略升级或账号凭据过期；尝试重新登录网盘或检查是否受账号每日流量频控限制 |
| RPC 发送失败 | 检查本地 Aria2/Motrix 是否已启动并监听 6800 端口；核对 RPC 路径与 Token 是否一致 |
| 跨域请求被浏览器拦截 | 在 Tampermonkey 弹窗中选择“总是允许向该域名发送请求”（`GM_xmlhttpRequest` 权限） |

- **脚本更新**：
  在 Tampermonkey / ScriptCat 管理面板中点击该脚本的“检查更新”；更新将直接获取上游最新版本，本次收录的快照保持不变。
- **脚本卸载**：
  在浏览器的脚本管理器仪表板列表中，找到“（改）网盘直链下载助手”，点击删除图标并确认即可彻底移除。
